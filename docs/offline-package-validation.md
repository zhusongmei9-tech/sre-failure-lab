## 验收边界

本轮没有可用的全新虚拟机，因此没有重装或覆盖 137 来冒充新机离线验收。安装器以受控执行器测试和独立源码审查验证，镜像内容以真实导出、摘要和平台检查验证；没有在经典 Docker 存储后端实际导入验收。已有 systemd 实机启停结论见 [此前记录](systemd-validation-137.md)。

Docker、Compose、systemd、Python 以及开发测试依赖不在此离线包内。该包不包含监控数据卷或当前运行状态备份，新机获得新凭据及新的部署身份。具体步骤与环境条件见 [离线包使用说明](../离线包使用说明.md)。
